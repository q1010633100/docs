---
title: 身份认证
description: 使用 Bearer Token 保护服务端 API 请求
---

示例 API 使用 Bearer Token 鉴权。每个请求都需要在 `Authorization` 请求头中携带访问密钥。

```http
Authorization: Bearer test_sk_replace_me
```

## 密钥类型

| 类型 | 前缀 | 用途 |
| --- | --- | --- |
| 测试密钥 | `test_sk_` | 本地开发和自动化测试 |
| 生产密钥 | `live_sk_` | 真实业务请求 |

<Warning>
   secret 密钥只能保存在服务端。不要将其放入前端环境变量、移动端安装包或公开仓库。
</Warning>

## 推荐实践

<AccordionGroup>
  <Accordion title="使用环境变量或密钥管理服务">
    本地开发可以使用环境变量；生产环境建议使用云厂商 KMS 或专用 Secret Manager，并限制读取权限。
  </Accordion>
  <Accordion title="定期轮换密钥">
    同时签发新密钥并保留旧密钥的短暂过渡期，完成应用升级后再吊销旧密钥。
  </Accordion>
  <Accordion title="记录审计日志">
    记录密钥创建、轮换和吊销事件，但不要记录完整密钥或 Authorization 请求头。
  </Accordion>
</AccordionGroup>
